# HR Management System

The complete ERD-based **Flask application** is in [`hrms/`](hrms/README.md). It includes all 16 HR tables, a web interface, MySQL setup SQL, a SQLite local preview, administrator login, CRUD forms, dashboard, and CSV exports.

Follow the [local setup guide](hrms/README.md) to run at **http://127.0.0.1:5000**.

The original Django starter (`Hr_Backend`, `employee`, `accounts`, and `manage.py`) is preserved for reference and is separate from the Flask application. The existing root `db.sqlite3` belongs to that starter; it is not used by the new application.
